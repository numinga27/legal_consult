Инструкция владельцу

Два документа для одного опросника

Схема определяет, куда ведёт каждый ответ. Документ содержит точные формулировки. Импорт связывает их по номерам вопросов и выводов.

1. Схема Draw.io

Вопросы обозначьте В1, В2, В3, конечные блоки — Вывод 1: название. Соедините блоки стрелками. Каждую стрелку подпишите точным текстом ответа из документа, например «Да» или «Нет».

В1Да → Вывод 1Нет → Вывод 2

Одно начало, минимум два ответа у вопроса, без циклов и оборванных стрелок. Загрузите одну страницу схемы в формате .drawio, .xml или .drawio.html. Лимит — 5 МБ.

2. Google Docs или Word

Каждый заголовок, ответ и абзац пишите с новой строки. Номера должны совпадать со схемой. Пример структуры:

В1: Текст первого вопроса?
А) Да
Б) Нет

Вывод 1: Заголовок первого результата
Краткий ответ для посетителя.

Вывод 2: Заголовок второго результата
Другой краткий ответ для посетителя.

Google Docs должен быть доступен на чтение по ссылке. Закрытый документ скачайте через «Файл → Скачать → Microsoft Word (.docx)» и загрузите вместо ссылки.

Подробные консультации и цены

Поддерживается формат исходника «Судебный приказ»: после краткого результата — три отдельных абзаца с целыми числами цен, затем подробная консультация. Числа служат разделителем и сохраняются как данные источника. Цены пакетов нужно отдельно проверить и заполнить в редакторе.

Пояснения после ответов сохраняются для редактора. Посетитель получает оценку только после завершения своей ветки. Подробная консультация не показывается в бесплатном результате.

3. Проверка и публикация

  1. Загрузите оба источника и нажмите «Разобрать документы».
  2. Проверьте первый вопрос, каждый ответ и переход, бесплатные результаты и тексты консультаций. Неоднозначные связи нужно указать вручную.
  3. Выберите раздел, подтвердите проверку и сохраните черновик.
  4. Пройдите разные ветки через «Пройти опросник». Затем нажмите «Опубликовать» в панели владельца.

Система проверяет структуру маршрутов. Юридический смысл и оценку вероятности проверяет автор материалов. Новый вариант сохраняется отдельно, предыдущий можно скрыть с сайта после проверки.
