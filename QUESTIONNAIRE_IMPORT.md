# Импорт опросников из Draw.io и Word

В панели администратора появилась ссылка **Импорт Draw.io + Word** (`/admin-import/`). Доступ разрешён только сотрудникам с `is_staff`. Импорт и прохождение не требуют новых Python-зависимостей. Сохранение заказов помощи требует миграции `0010_helporder` (`python manage.py migrate` перед запуском обновлённого приложения).

## Работа владельца

1. Загрузить схему `.drawio`, `.xml` или `.drawio.html` и файл `.docx` с текстами (до 5 МБ каждый).
2. Проверить замечания, первый вопрос, переходы каждого ответа, бесплатные результаты и подробные консультации. Повторяющиеся вопросы показаны отдельными блоками: они могут вести к разным итогам.
3. При необходимости выбрать правильные переходы и отредактировать тексты прямо в форме. Нажать **Проверить изменения**.
4. Выбрать раздел сайта, отметить проверку материалов и сохранить. По умолчанию создаётся черновик, доступный только администратору. Отметка **Сразу открыть опросник посетителям** включает его в каталог.
5. **Скачать пакет** сохраняет тексты и алгоритм в JSON. Его можно загрузить через **Восстановить из ранее сохранённого пакета** без повторного разбора двух исходников.

Повторное сохранение идентичного пакета в том же разделе возвращает существующий опросник. Включение публикации переводит такой черновик в активное состояние. Изменённый пакет создаёт отдельную версию, не удаляя вопросы, ответы или историю прежней. Чтобы скрыть прежнюю версию после проверки новой, можно снять `is_active` в стандартной Django admin.

Форма сохраняет выбранный раздел. Устаревшая вкладка не может перезаписать черновик, открытый позже в другой вкладке. Если на один ответ в схеме приходится несколько стрелок, импорт требует явно выбрать правильный переход.

## Формат следующих исходников

Word: заголовки `В1: Текст вопроса`, `В2.1: …`; ответы `А) Да`, `Б) Нет` с пояснениями под ними; результаты `Вывод 1: Заголовок`. Три отдельных числовых абзаца после бесплатного результата отделяют его от подробной консультации. Это соглашение текущих исходников: числа сохраняются как исходные цены и автоматически не назначаются услугам.

Draw.io: вопросы с теми же номерами, пронумерованные выводы, стрелки с прикреплёнными началом и концом и подписями ответов. Поддержаны зелёные стрелки `#33FF33`, `#66FF66`, `#00FF00` как «Да» и красные `#FF0000`, `#FF3333` как «Нет». Несколько страниц необходимо экспортировать по одной. Если рисунок содержит короткие блоки `В1`, используется это подробное дерево вместо поясняющего эскиза с полными текстами.

Произвольные рисунки и произвольно оформленный Word не обещают импорт без ручной проверки. Непривязанные/неподписанные связи не угадываются. Циклы, недостижимые блоки и выводы, пустые ответы и несуществующие переходы блокируют сохранение. Если в схеме отсутствуют целые вопросы или итоги, следует сначала исправить исходники.

## Границы готовности

Для всех импортированных опросников действует сценарий эталона: вопрос → ответ → сразу следующий вопрос по стрелке Draw.io → бесплатный результат только на конечном узле. Промежуточных экранов и кнопки «Продолжить» нет. Пояснения к ответам из Word сохранены в пакете и доступны редактору, но не выдаются посетителю между вопросами. Краткая оценка берётся из соответствующего итогового вывода Word. Количество вопросов зависит от ветки; для судебного приказа — от 1 до 9. Старая сессия, остановленная на пояснении, учитывает уже выбранный ответ однократно и продолжает ветку. Возврат обрезает прежнюю ветку; обновление страницы сохраняет текущий шаг. Состояние проверяется сервером, формы используют CSRF, повторный запрос со старой ревизией не применяет ответ второй раз.

На завершённом результате сначала показан **Краткий вывод:** с вероятностью и причиной из соответствующего текста Word, затем три пакета с названиями и составом эталона: **Правовая оценка ситуации** (консультация + план), **Документальное сопровождение** (план + документы), **Максимальная помощь** (все три услуги). Вероятность не вычисляется и не подменяется общим значением: если исходный вывод её не содержит, процент не добавляется.

Для «Судебного приказа» по прямому поручению владельца скопированы цены открытого результата эталона от 13.09.2026: **298 / 498 / 697 ₽**. Они записаны в `offer_prices` пакета и применяются ко всем его итогам. Исходные цены Word сохранены в `source_prices` без изменения. Для следующих импортов цены задаются в форме владельца и сохраняются при экспорте JSON; пустая цена отображается как «Цена уточняется». Кнопки **Получить помощь** открывают форму ФИО/почты/телефона выбранного пакета. Пока доступно сохранение неоплаченного заказа и его просмотр в «Мои заказы» текущей сессии браузера. Сумма, состав и итог фиксируются сервером; чужие заказы закрыты, повторная отправка не создаёт дубль. Аккаунт, оплата, письма и выдача материалов не имитируются. Подробное сравнение с эталоном и оставшаяся работа: REFERENCE_GAP_AUDIT_2026-09-13.md.

Кнопка **Пройти опрос заново** расположена после пакетов. Она работает и с устаревшей вкладки. Обновление самого результата сохраняет его; повторный вход в завершённый опросник из каталога начинает новое прохождение. Незавершённый опрос при входе из каталога продолжается с текущего шага.

Подробные консультации сохранены для владельца и не отправляются посетителю в HTML бесплатного результата. Исходные юридические тексты и проценты перенесены без юридической экспертизы. В паре файлов нет самостоятельных шаблонов документов и отдельно размеченных пошаговых планов. Платёжная выдача, почта и генерация заполненных документов не подключены в этой итерации.

Импортированные опросники используют новое поле-формат внутри существующего `workflow`. Старые редакторы перенаправляют к импорту, старые API изменения/прохождения и демонстрационной оплаты не принимают эти опросники. Старые опросники также проходят через единый пошаговый экран. Переходы читаются из существующих связей базы без изменения юридических материалов. Если у ответа отсутствует вывод, посетитель видит состояние «Материалы готовятся» и может вернуться назад; случайный результат не подставляется. Старые API прохождения и имитации оплаты отключены для всех опросников.

## Проверки и запуск

В настроенном Django-окружении: `python manage.py test core`. Проверяются разбор XML, HTML и сжатого Draw.io, повреждённые входные данные, ограничения графа, идемпотентность, доступы, CSRF, возврат, возобновление, все пути по независимой матрице условий из исходников и отсутствие выдачи платного текста/создания платежей.

Локальный демонстрационный сервер находится вне репозитория в `local_home_preview.py`: он копирует только каталог в RAM и добавляет готовый пакет. `/preview-owner/` существует исключительно в этом loopback-сервере и даёт вход в демонстрацию владельца; в production URL отсутствует. Не использовать этот скрипт для развёртывания. Изменения демо исчезают при перезапуске; JSON-пакет и код сохранены на диске.
