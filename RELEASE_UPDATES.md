## Порядок поставки и откат

1. Из legal_consultant: `python manage.py test core --noinput`. Инструменты и зависимости сервера: deploy/requirements-recovery.txt.
2. Commit и push в main. Сверить SHA origin/main. Таймер либо `systemctl start legal-consult-deploy.service` запускает /usr/local/bin/legal-consult-deploy.
3. Скрипт deploy/deploy.sh проверяет проект, миграции, тесты без боевых платёжных ключей, делает резервную копию БД, собирает static, переключает current, перезапускает Supervisor и сверяет health с SHA.
4. Проверить журнал legal-consult-deploy.service и /home/numinga/.local/share/legal-consult-deploy/success. Релиз хранится в /home/numinga/.local/share/legal-consult-deploy/releases/<SHA>. Это исходный веб-релиз, отдельного подписанного бинарного файла нет.
5. При сбое скрипт восстанавливает прежние симлинки приложения и static. БД автоматически не откатывается. Для отката успешного выпуска предпочтителен проверенный revert-коммит с новым deploy; восстановление БД требует отдельного решения.
