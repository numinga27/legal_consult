## Подключение

1. Владелец магазина регистрирует кабинет Platega и проходит подключение магазина k-urist.ru. Merchant ID и API Secret выдаются при подключении и доступны в настройках кабинета.
2. В настройках Platega, раздел Callback URLs, указать `https://www.k-urist.ru/payments/platega/callback/`.
3. Администратор сервера сохраняет `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET` и `PLATEGA_ENABLED=0` в существующем защищённом `/home/numinga/.config/legal-consult/app.env`. Файл должен принадлежать numinga и иметь права 600. Секрет вводить непосредственно на сервере, не отправлять в чат и не добавлять в Git, логи или командную строку.
4. Перезапустить приложение командой `sudo supervisorctl restart legal_consult`. Убедиться, что Platega принимает HTTPS callback с заголовками X-MerchantId и X-Secret. До подтверждённого подключения оставить флаг 0.
5. Согласовать с владельцем контрольный платёж. На время проверки установить `PLATEGA_ENABLED=1`, перезапустить сервис. Проверить создание ссылки, успешный платёж, повтор callback, отмену и возврат. Проверить доступ к материалам из правильного аккаунта. Если подтвердить работу не удалось, вернуть флаг 0. Реальная оплата требует отдельного согласования суммы.

Проверить состояние приложения: `sudo supervisorctl status legal_consult`. В этой установке процессом управляет Supervisor.

## Поведение сайта

- Стоимость берётся из сохранённого заказа. Поля браузера не могут её изменить. Каждая выбранная услуга оплачивается отдельным заказом.
- Оплата доступна только авторизованному владельцу заказа. Для консультации и плана нужен непустой подготовленный текст. Для документов нужна доступная пара DOCX и PDF.
- Возвращение со страницы оплаты само по себе не открывает материалы. Callback и кнопка «Проверить оплату» запрашивают статус через API Platega и сверяют ID, сумму, валюту и привязку к заказу.
- Повтор уведомления не создаёт повторную выдачу. Полный возврат закрывает доступ, спор временно его приостанавливает. Частичный возврат сохраняет доступ. Запоздалое подтверждение не открывает заказ после полного возврата.
- При тайм-ауте создания счёта записывается UNKNOWN. Повторная попытка не создаёт новый счёт автоматически. Поддержка должна сверить заказ с кабинетом Platega и установить фактический исход. Не удалять попытку и не запускать ещё один платёж вслепую.
- При выключении новых оплат callback продолжает обрабатывать уже созданные платежи, если ключи остаются настроенными.
- Ранее сохранённые заказы сохраняют свой текст и стоимость. Новый импорт не подменяет старые заказы и ручные исправления опросника.
